SETTING UP A NEW PI 5 FOR SHAPPE GUIDE
======================================
Checked against the working rig on 2026-09-28 (Raspberry Pi 5, Arducam CamArray
UC-512 + 4x IMX519, Hailo-10H, RPLIDAR A2M12, 6x A121 radar, MPU-6500 on SPI0).

1. Camera driver (Arducam Pivariety packages)
---------------------------------------------
mkdir ~/drivers && cd ~/drivers
wget -O install_pivariety_pkgs.sh https://github.com/ArduCAM/Arducam-Pivariety-V4L2-Driver/releases/download/install_script/install_pivariety_pkgs.sh
chmod +x install_pivariety_pkgs.sh
./install_pivariety_pkgs.sh -p libcamera_dev
./install_pivariety_pkgs.sh -p libcamera_apps

2. /boot/firmware/config.txt (then reboot)
------------------------------------------
camera_auto_detect=0
dtoverlay=imx519,cam1
dtparam=i2c_arm=on
dtparam=spi=on          # MPU-6500 on SPI0 CE0 -> /dev/spidev0.0

3. System packages (apt — these are NOT on PyPI in a usable form)
-----------------------------------------------------------------
sudo apt update
sudo apt install -y python3-picamera2 python3-libcamera libcamera-apps libcap-dev espeak-ng i2c-tools
# Hailo-10H runtime: install h10-hailort (5.1.1 on the rig) per Hailo's instructions.

The user needs these groups (log out and in after adding):
sudo usermod -aG dialout,spi,i2c,video,audio,gpio $USER

4. The app
----------
cd ~
git clone https://github.com/The-Shappe/lidar.git
cd lidar
python3 -m venv --system-site-packages venv    # REQUIRED: picamera2 and hailo come from apt
./venv/bin/pip install --upgrade pip
./venv/bin/pip install -r requirements.txt     # pinned; do not add numpy==1.25 on top
# The models (model/*.hef + model/metadata.yaml) come with the checkout today.

5. Run it
---------
./start_lidar.sh                               # by hand, http://<pi-ip>:8000
./deploy/install-service.sh                    # or: as a service that starts at boot (README)

6. Hardware checks
------------------
python -m rplidar /dev/ttyUSB0 256000          # LiDAR (stop the app first: one owner per port)
./venv/bin/python -m utils.radar_utils --check # radar boards present / measured
./venv/bin/python -m utils.gyro_reader --check # IMU: turn right, yaw must go POSITIVE
hailortcli scan                                # NPU
rpicam-hello --list-cameras                    # camera and its sensor modes

CamArray HAT channel mode — I2C BUS 11 on the Pi 5, controller 0x24, register 0x24.
(Older notes said bus 10; that numbering was a Pi 4's. `i2cdetect -l` to check.)
The HAT forgets its mode on power-cycle; the app needs 4-in-1 (0x00).
  Camera 0 only:     sudo i2cset -y 11 0x24 0x24 0x02
  Camera 1 only:     sudo i2cset -y 11 0x24 0x24 0x12
  Camera 2 only:     sudo i2cset -y 11 0x24 0x24 0x22
  Camera 3 only:     sudo i2cset -y 11 0x24 0x24 0x32
  All 4 (2x2 grid):  sudo i2cset -y 11 0x24 0x24 0x00
./camera_web.py --mode 4ch --port 8080         # live view of all four in a browser (app stopped)
