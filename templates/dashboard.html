How to read the front camera

Only things that can hurt the user are named: vehicles, people, animals, poles, hydrants, benches (trees and bollards need the custom model). Nothing else is detected at all; chairs, tables and laptops never appear here (config.DETECTION_CLASSES), and the laser still steers round them, unnamed. Each box says how far away it is: 10.5 ft is the laser's range in that direction; ≈38 ft is guessed from the box's size where the laser has nothing that matches (the lens angle is assumed); ≤4 ft means the frame cuts the box off, so it is at most that far. A named object must overlap the shaded middle band, be tall enough to be near, and the laser or radar must already have something on the path. A vehicle in the band that is getting bigger is approaching (red): the user is told to move away from the half it is in. A stopped vehicle while the user stands still is be careful (amber). The green line is where the guide is steering the user past things in the way: round one side, or through a gap.
