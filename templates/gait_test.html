Pace is cadence × stride, counted from footfalls in |a| — never integrated from acceleration, which drifts to metres within seconds. Shown in km/h, with m/s alongside because that is the unit the API and config use. Strap the board on and walk normally; on a desk it correctly reports nothing. This reads the running guidance app, so it does not need the app stopped.
