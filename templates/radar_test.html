One card per board. Wave a hand ~1.5 ft in front of one sensor — its distance drops and its bar jumps, which is how you tell which physical board is which serial. Anything nearer than the blind zone (shaded red, left of each bar) is invisible to the sensor by design. Measured Hz and lag are the numbers to watch when checking whether the USB link keeps up with all six boards running at once.

Bearing calibration

Which way each board FACES, in degrees clockwise from straight ahead. 0° is dead ahead. Wave a hand at one board, see which row's number jumps, then pick its bearing.

This is a measurement, not a preference — it is the same table the guidance layer steers on, and a board with no bearing is refused rather than guessed at.
